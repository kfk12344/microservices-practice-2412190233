# 个人健康饮食记录管理系统 (Health & Diet Tracker)

## 📖 项目简介

个人健康饮食记录管理系统是一个帮助用户科学管理日常饮食、运动与体重的全栈应用。通过记录每日三餐、运动消耗和身体数据，系统自动计算热量收支，生成可视化健康报表，帮助用户达成减脂、增肌或保持健康的目标。

## 🎯 业务背景

随着生活水平提高，人们对健康管理的需求日益增长。然而，大多数人缺乏专业的营养知识，难以准确掌握每日热量摄入与消耗。现有的健康 App 往往功能繁杂或收费昂贵。本项目旨在提供一个轻量、免费、易用的个人健康管理平台，让用户能轻松记录、直观分析、科学调整。

## 👥 目标用户及需求

| 用户角色 | 核心需求 |
| :--- | :--- |
| **普通用户** | 记录三餐饮食、记录运动消耗、追踪体重/围度、查看热量收支报表、设定健康目标 |
| **营养师 (可选)** | 查看用户饮食数据、给出饮食建议、制定个性化食谱 |
| **管理员** | 管理食物库（热量、营养成分）、管理运动库、管理用户账号、系统监控 |

## 🧩 功能模块划分

### 1. 用户与认证模块
- 用户注册/登录（JWT 认证）
- 个人档案管理（身高、体重、年龄、目标）
- 角色权限管理（用户/营养师/管理员）

### 2. 饮食记录模块
- 食物库查询（按名称、分类、热量）
- 添加/编辑/删除三餐记录（早餐、午餐、晚餐、加餐）
- 自动计算每餐及每日总热量、蛋白质、脂肪、碳水

### 3. 运动记录模块
- 运动库查询（跑步、游泳、力量训练等）
- 添加/编辑/删除运动记录（时长、强度）
- 自动计算运动消耗热量

### 4. 身体数据模块
- 记录体重、体脂率、腰围、胸围等
- 生成体重变化趋势图
- 设定目标体重与截止日期

### 5. 报表与分析模块
- 每日/每周/每月热量收支报表
- 营养素摄入比例饼图
- 运动消耗统计
- 健康目标达成进度

### 6. 消息提醒模块 (后续扩展)
- 定时提醒记录饮食
- 目标达成祝贺通知
- 营养师建议推送
