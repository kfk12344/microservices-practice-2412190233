### 终端 2：执行 curl（另开一个 PowerShell 窗口）

**① 新增一餐 → 201**

```powershell
curl.exe -X POST http://localhost:8080/api/meals -H "Content-Type: application/json" -d '{\"eater\":\"demo-user\",\"mealType\":\"LUNCH\",\"eatenAt\":\"2026-09-30T12:30:00\",\"note\":\"工作餐\",\"items\":[{\"foodId\":1,\"portionGrams\":200},{\"foodId\":3,\"portionGrams\":150}]}'
```

截图里要有 `totalCalories: 431.5` → 存成 `03-post-meal-201.png`

**② 违反热量上限 → 422**

```powershell
curl.exe -X POST http://localhost:8080/api/meals -H "Content-Type: application/json" -d '{\"eater\":\"demo-user\",\"mealType\":\"LUNCH\",\"eatenAt\":\"2026-09-30T12:30:00\",\"items\":[{\"foodId\":1,\"portionGrams\":2000}]}'
```

截图里要有 `"status": 422` 和 `违反规则：R3` → 存成 `04-business-rule-422.png`

**③ 路径参数类型错误 → 400**

```powershell
curl.exe http://localhost:8080/api/meals/abc
```

截图里要有 `"code": "INVALID_PARAMETER_TYPE"` → 存成 `08-invalid-parameter-type-400.png`

> 注意：② 必须在 ① 之后马上做，且两条都用同一个 `eatenAt`。
> 如果重复执行 ① 会返回 422（提示"重复提交"），那是规则 R2 生效，属正常。
> 想重新演示 ①，把 `eatenAt` 改一个没记录过的时间即可。
